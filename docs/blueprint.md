# **App Name**: Vivah Profile Maker

## Core Features:

- Biodata Form: Intuitive multi-section form for entering personal, family, job, and property details.
- Multi-Language Input: Allows users to input biodata in any language with full Unicode support and language-specific font options during template selection.
- Live Preview: Live preview of entered biodata, accessible via a 'Preview' button that instantly shows the full biodata with the chosen template.
- Template Selection: Offers a selection of beautifully designed templates with different background designs, fonts, and layouts, easily extensible for future designs.
- Export Options: Allows users to export/download the biodata in multiple formats: PDF, Image (PNG/JPEG), and Word Document (.docx).
- Offline & Draft Safety: Autosaves data to localStorage every few seconds to prevent data loss during page refresh or internet failure, syncing to MongoDB when the internet is restored.
- AI Profile Assistant: Uses an AI tool to automatically suggest profile content improvements based on entered details, such as phrasing or completeness.

## Style Guidelines:

- Primary color: Soft coral (#F08080) for a warm and inviting feel, symbolizing love and commitment.
- Background color: Light desaturated beige (#F5F5DC) providing a neutral and elegant backdrop.
- Accent color: Muted gold (#B8860B) used sparingly to highlight key elements and calls to action.
- Headline font: 'Playfair', a modern sans-serif with an elegant and high-end feel.
- Body font: 'PT Sans', a humanist sans-serif with a modern look.
- Elegant and subtle icons related to family, career, and interests.
- Clean and spacious layout with clear sections for easy readability on all devices.
